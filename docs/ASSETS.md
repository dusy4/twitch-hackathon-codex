# Asset provenance and redistribution gates

Website geometry, original portal shader, anonymous voxel crowd, particles, procedural gesture additions and Web Audio cues are code-generated. Named characters now use Kay Lousberg's **KayKit Adventurers** under CC0-1.0. The four official GLBs and license are in `apps/web/public/models/kaykit`; `manifest.json` pins source commit, SHA256, bytes, actual clip names and mesh statistics. Each inspected file contains 41 joints, 76 animation clips, embedded texture data and roughly 5.7–7.0k triangles including optional accessories. They were downloaded from the author's official GitHub repository at commit `672074b73ba276876a19e8816ecdc5241817ab47`; no purchased EXTRA assets are included. No Minecraft or Nintendo model/texture/audio assets were copied. Fonts are system UI/Georgia/monospace. No OpenAI-generated raster images were needed.

`npm run licenses` writes `artifacts/dependency-licenses.json`. The current inventory contains MIT, Apache-2.0, BSD-3-Clause, ISC, MPL-2.0 and BlueOak-1.0.0 dependencies, with no unknown package license fields. This metadata inventory is not a substitute for preserving notices in distributed binaries. npm audit reports no known advisories at the recorded validation point.

## Vision runtime and model

`@mediapipe/tasks-vision` 1.1.1 declares Apache-2.0. The EfficientDet-Lite0 int8 model was downloaded from the official [MediaPipe model distribution](https://storage.googleapis.com/mediapipe-models/object_detector/efficientdet_lite0/int8/1/efficientdet_lite0.tflite), SHA-256 `0720bf247bd76e6594ea28fa9c6f7c5242be774818997dbbeffc4da460c723bb`. Source URL/hash are recorded by `setup:vision`. [Official object detector documentation](https://developers.google.com/edge/mediapipe/solutions/vision/object_detector) describes the model, but does not establish all model-weight redistribution terms. Do not infer weight licensing from the runtime’s license. Production Docker context excludes local model/WASM assets until distribution review is complete. Local evaluation copies are present on this workstation and ignored by Git.

## Android native distribution — 2026-10-29

`apps/android` builds the same pinned KayKit CC0 GLBs into generated derivatives with root translation channels and unselected handheld weapon nodes removed. Source files are preserved; derivative hashes and operation receipts are included in the APK. Khronos glTF-Validator reports zero errors/warnings for all four derivatives (`artifacts/android-model-validation.json`).

**Android on-device detector (0.5.0-northstar).** `apps/android/app/src/main/assets/models/efficientdet_lite0.tflite` is the official MediaPipe EfficientDet-Lite0 **float16** COCO model, downloaded 2026-10-29 from https://storage.googleapis.com/mediapipe-models/object_detector/efficientdet_lite0/float16/latest/efficientdet_lite0.tflite (GCS generation 1682636014261146, Last-Modified 2023-04-27), 7,254,339 bytes, SHA-256 `4b59100025bea1235a84c1038879a6cccc9f6c49f5e41144e91e74d99e780993`. Recorded as Apache-2.0 (MediaPipe/TensorFlow EfficientDet-Lite distribution); the same caveat as above applies — Google's model page does not restate weight-redistribution terms, so confirm before a public store release. Runtime: `com.google.mediapipe:tasks-vision:1.2.0` (+ `tasks-core`), Apache-2.0 POM declaration, minSdk 24; its `libmediapipe_tasks_jni.so` has 16 KiB PT_LOAD alignment and the APK passes `zipalign -c -P 16`. Notice text: `apps/android/app/src/main/assets/notices/NOTICE.txt`. Camera frames stay on the phone; only boxes/classes/confidences go to the paired server.

The resolved Android runtime inventory has 173 components (regenerated for 0.5.0-northstar) with declared or inherited POM license metadata (`artifacts/android-dependency-licenses.json`), reproduced with Gradle `:app:writeRuntimeDependencyList` then `node scripts/android-license-inventory.mjs`. This is a declaration audit, not an advisory scan. Apache/MIT/WebRTC BSD and bundled third-party texts, component metadata and ARCore's separate Additional Terms reference are bundled in `apps/android/app/src/main/assets/notices`; KayKit notices remain alongside the models. SceneView/Filament/AndroidX/Kotlin/OkHttp are not substitutes for Google's ARCore terms. No Mario, libsm64 ROM-derived assets or author reference-video frames are included in the app.
