# ADR-011: IRC Live input and Extension controllers

2026-10-31. Implement three dependent vertical slices: anonymous IRC -> existing chat/world path and device-authorized lifecycle; shared held steering -> cancellation/expiry; Extension JWT EBS -> bundled responsive controller and integration tests. Preserve port 3412 and the separately owned Unity project. No public deployment or secrets in source.

An IRC reader belongs to a paired world, not a browser. Live selection changes the snapshot mode to LIVE TWITCH; simulator tools remain available only under their existing guards. Twitch numeric user IDs resolve to the existing accounts. Ordinary chat only directs participating viewers; explicit commands can join. IRC is read-only and uses bounded work, message deduplication, heartbeat and capped reconnect. IRC raid USERNOTICE is the raid source when this reader is selected; the existing credentialed EventSub integration is independent and must not be configured to duplicate the same channel input.

Steering is a server action, separate from declarative planner steps. It cancels an actor's plan, and a new plan cancels steer, including late model completions through an actor instruction fence. World positions remain normalized image coordinates; camera-relative direction is also exposed for the native renderer. Renderer physics still owns measured local geometry; this change cannot establish AR grounding.

Extension tokens use HS256 and the decoded Extension secret. Only viewer/moderator/broadcaster roles, unexpired tokens and a mapped numeric channel are accepted. No browser-selected actor or room. Opaque IDs stay namespaced; shared IDs use chat accounts. SSE uses Authorization through fetch, not URL credentials, and expires with the JWT. Origin checks supplement signature authorization.

The requested focused keyboard input is a Local Test feature flag. Twitch policy 2.3 forbids keyboard shortcuts: the normal review build disables it, and the d-pad remains operable with focus/Enter/Space. Component/panel/mobile use full-frame layouts; only the video overlay collapses, preserving Twitch component frame controls. Bundle only Latin Space Grotesk (OFL), beUI's base Button (MIT), and React Bits ClickSpark (MIT + Commons Clause); no remote fonts or decorative assets. Owner's explicit dark glass/violet/mint direction takes precedence over generic design-skill palette bans. Feedback motion is limited to controls and an emote burst, with reduced-motion support.

Fresh sources: [IRC](https://dev.twitch.tv/docs/chat/irc/), [Extension building](https://dev.twitch.tv/docs/extensions/building/), [JWT/helper reference](https://dev.twitch.tv/docs/extensions/reference/), [Extension policies](https://dev.twitch.tv/docs/extensions/guidelines-and-policies/). Anonymous justinfan support is not promised by the current official authentication guide; real anonymous delivery requires a live smoke check, and failure is shown as degraded status rather than silently substituting fixtures.
