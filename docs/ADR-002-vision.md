# ADR 002: opt-in image-space surface estimation

Observed in actual licensed dog footage: a bounding box can include a raised tail, so placing a character at its top-center produces an obvious floating contact. A bounding box alone is insufficient evidence for silhouette contact.

Add an optional local-only segmentation worker. It receives an ephemeral ImageBitmap, segments one permitted animal/furniture target, extracts a confident upper contour near the target center, and returns only an anchor. Raw masks/frames are not transmitted or stored. Cache anchors relative to tracked boxes for a short interval. Reset epoch and dispose worker/bitmaps on disconnect. No human segmentation or re-identification is performed.

Official current MediaPipe documentation recommends the v2 stateful InteractiveSegmenter. On this workstation, v2 initialized and encoded an image but stalled at native decoding for the tested window. The packaged runtime also declares BrushMode as an enum without exporting a runtime value. A tested fallback uses InteractiveSegmenterLegacy with the exact 6,227,884-byte MagicTouch float32 checkpoint, SHA-256 `e24338a717c1b7ad8d159666677ef400babb7f33b8ad60c4d96db4ecf694cd25`. Google's model card identifies the original checkpoint architecture and Apache-2.0 terms. Preserve its notices. V2 is not the active pipeline.

This is a deliberate, evidence-driven compatibility choice. Reassess the stateful API after upstream/runtime/device changes. Segmentation is experimental, defaults off, and is not calibrated visual quest proof. Native AR anchors/depth remain a separate implementation path. Detector misses, low light, near-overlapping targets and camera movement still need broader evaluation.

Sources: [current web API](https://developers.google.com/edge/mediapipe/solutions/vision/interactive_segmenter/web_js), [legacy comparison](https://developers.google.com/edge/mediapipe/solutions/vision/interactive_segmenter), [MagicTouch model card](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20MagicTouch.pdf). Exact runtime signatures were also checked in the installed official package's declaration and source files.
# Follow-up: observation lifetime and local worker bounds, 2026-10-28

Timestamped licensed-video traces exposed a same-class dog re-observation after 805 ms with 0.742 box IoU, just beyond the previous 800 ms ID-history horizon. Another trace contained a brief dog/horse/dog label flip. The local association history and server missing-update retention now share the existing 1,200 ms hard observation lifetime. Missing updates retain the last real observation timestamp; they never mint a new timestamp or label. A prolonged gap still expires the target and stops its action. Explicitly observed anchors outside a configured crop are removed immediately. Geometry edits reset the scene epoch.

The optional silhouette path resizes inputs to at most 640px in either dimension, expires its relative-anchor cache, bounds it to 32 entries, and terminates a stalled worker after four seconds. Source shutdown terminates the worker immediately; worker/epoch identity checks discard late bitmap tasks. These changes address resource/lifecycle behavior, not model calibration. Camera rewards remain disabled.

## Worker scheduling and observation provenance

Object classification also runs in a dedicated worker, following [Google’s web detector guidance](https://ai.google.dev/edge/mediapipe/solutions/vision/object_detector/web_js). Only one frame is in flight per model. A 4-second watchdog terminates stalled inference even when the video stops advancing; optional segmentation initialization is bounded to 30 seconds. Three consecutive silhouette results older than 1.5 seconds disable that optional worker and expose the bounding-box fallback status.

Classification retains its source-frame time (`classifiedAt`) and expires after two seconds independently of patch observations. Late detections can advance only through contiguous, actually sampled grayscale frames (maximum gap 250 ms). A memory-only ring retains at most 40 frames and two seconds, bounded to 256×256 pixels per frame. It is cleared on source stop; no frames/masks leave the browser or enter disk storage. Worker bitmaps are bounded to 640×640 and closed after inference.

Metadata delivery is decoupled from sampling: one abortable HTTP request may be in flight, with one coalesced newest packet waiting. Epoch/lifecycle guards reject obsolete workers and completions. This improves responsiveness but does not establish segmentation quality; the strict current silhouette-contact gate remains unresolved. Real-video bounding-box actions and deliberately delayed optional-worker fallback pass independently.

## Classifier reconciliation and transformed preview

A classifier response used to replace the entire current track list, even when it was empty or could not be replayed through the frame ring. It now reconciles against newer, genuinely observed positions within the original class lifetime. Missing/rejected classifications do not erase current observations, and another object's class result cannot refresh a retained class. Model scores are no longer decremented per sampled frame: the former fixed decrement made high-frame-rate sampling lose confidence sooner for the same source evidence. Classification timestamps and image-agreement rejection remain the independent freshness/motion gates. Silhouette cache lifetime now starts at its source frame rather than response arrival.

The companion draws source pixels and diagnostic boxes in the configured OBS output coordinates. Crop, mirror, rotation and viewport placement use the same math as the exported composite. Canvas width/height describe the OBS output rather than raw video dimensions; portrait sources are bounded in both axes. A synthetic four-color browser stream verifies transformed pixel colors and overlay alignment (`artifacts/capture-geometry.json`). This is a rendering check, not a perception benchmark. Both dog tests passed in one focused run after reconciliation/confidence changes; a later run again lost a classification before command submission, while the silhouette action passed. Reliability remains an open gate.
